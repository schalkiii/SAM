工作模式

直通模式

撤销 DNS 劫持，系统改用网络下发的 DNS。仅切换直通时只改 DNS 劫持规则并暂停/恢复 Mihomo，不会重启 AGH/SmartDNS，缓存与统计也保留；适合校园网、认证热点、企业内网。开启期间会暂停 Mihomo（TUN 仍会劫持 DNS），关闭后自动恢复

DNS 结构模式

决定 53 端口优先转发给谁；未运行的服务会自动跳过。模式 2：Mihomo → AdGuardHome → SmartDNS（代理优先）
模式 1：AdGuardHome → Mihomo → SmartDNS（过滤优先）

切换后刷新网络

改动直通开关、DNS 模式或 DNS 端口后开关一次飞行模式，让系统和 App 立刻重新解析；WiFi 会短暂断开重连。服务异常恢复时的自动刷新 10 分钟内最多一次，手动刷新不受限

上游解析与自动分流

AdGuardHome

Mihomo DNS 增强模式

TUN 网卡名

默认 Meta

SmartDNS 调优

响应模式

first-ping 综合最快；fastest-ip 要等全部测速（最慢）；fastest-response 不等测速（延迟最低）

测速方式

none / ping / tcp:443 / ping,tcp:80,tcp:443。默认 ping,tcp:80,tcp:443；移动网络下 ping 常被限速，可改为 tcp:443

缓存 TTL 下限

秒，范围 60-86400。上游 TTL 低于该值时按该值缓存。缓存由 SmartDNS 承担（AdGuardHome 不缓存），设太小会导致缓存形同虚设、每次都重新测速，默认 600

双栈 IP 优选

对 A/AAAA 做时延比较；不用 IPv6 时关掉可少一次等待

工具

日常启停、开关和参数在「服务」「设置」页；这里是一次性维护命令。

模块与诊断

「激活待更新版本」只用于刚刷入、还在 modules_update 的情况；「修复 / 免重启激活」会在 active/update/previous 间自动恢复，适合临时 root 和软重启后模块目录丢失。「一键诊断」只读采集服务/端口/配置校验/防火墙/DNS/MTU，并采样 15 秒 IPv6 阻断增量；「自动停止分析」直接判断是手动/WiFi 停止、watchdog 拉起，还是系统/小米杀后台，并列出 auto-stop 取证。

日志取证

「一键收集日志」把 module.log 三代、auto-stop 取证、三服务自身日志、完整诊断、进程 cgroup、iptables、dmesg/logcat 击杀记录汇总成一个报告，保存在 /data/adb/SAM-debug（root-only，保留最近 10 份），执行后会把路径显示在下方输出框。「导出报告到下载目录」额外复制一份到 /sdcard/Download，方便直接发送；报告含订阅链接与节点地址，发送前确认渠道。

配置备份

备份内容: setting / AdGuardHome / SmartDNS / Mihomo / 黑白名单 / hosts / 定时，保存在 /data/adb/SAM-backup（root-only），保留最近 5 份。

广告与 Hosts

这些按钮是立即执行一次；是否随服务自动屏蔽由「设置 → 屏蔽 App 广告文件」决定。「清理已卸载 App 的锁定」只解除 immutable 并删除空壳；带「及备份」会同时删除孤儿 .samhold 备份，不可恢复。

网络与配置维护

「刷新网络」等价于开关一次飞行模式，WiFi 会短暂断开。「重写配置」只改写文件，不会重启服务；需要生效请回「服务」页重启。DNS 规则状态与重建在「监控 → 健康状态」。

定时任务

格式: 分 时 日 月 周 命令，一行一条，# 开头为注释；也支持 @daily 这类快捷键。由 busybox crond 执行，保存后下一分钟自动生效，无需重启服务。默认示例见上方输入框提示；清空全部行再保存=删除所有定时任务(定时文件每天自动备份，可恢复)。

危险操作

「更新内置组件」从 GitHub 拉取 SmartDNS / AdGuardHome / Mihomo，耗时较长且会重启服务；AGH 大版本升级会迁移配置 schema，回退旧版本后若无法启动，用「重置 AGH 配置」恢复模板。重置会先完整备份并保留单文件副本，但会丢失 AGH 面板密码与自定义过滤规则。卸载会立即停止服务并删除模块目录，配置备份保留。
