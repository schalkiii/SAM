工作模式

直通模式

撤销 DNS 劫持，系统改用网络下发的 DNS。服务与 WebUI 保持运行，适合校园网、认证热点、企业内网

DNS 结构模式

模式 2：Mihomo → AdGuardHome → SmartDNS
模式 1：AdGuardHome → Mihomo → SmartDNS

切换后刷新网络

改动直通开关、DNS 模式或 DNS 端口后开关一次飞行模式，让系统和 App 立刻重新解析；WiFi 会短暂断开重连

服务开关

SmartDNS

上游解析与自动分流

AdGuardHome

广告拦截与查询日志

Mihomo

代理与 TUN，需要填写订阅地址

Mihomo IPv6

允许代理 IPv6 流量

阻断 IPv6 DNS

拦截本机 IPv6 的 53 端口查询，避免绕过过滤

DNS 参数

AdGuardHome DNS 端口

默认 5300，改完需确保不与其他程序冲突

Mihomo DNS 端口

默认 1053

Mihomo DNS 模式

fake-ip 响应更快，redir-host 兼容性更好

TUN 网卡名

默认 Meta

其他

Hosts 挂载

用模块 hosts 覆盖系统 hosts(广告拦截、GitHub 加速)

定时任务

按 etc/crontabs/root 定时执行

屏蔽 IP 规则

按 ip.sh 中的名单拦截目标地址

屏蔽 App 广告文件

清空并锁定部分 App 的广告缓存目录(chattr +i)，卸载时自动恢复。App 启动异常时优先关掉这项
点击「查看影响范围」列出会被处理的 App 与路径

卸载时备份 Mihomo 配置

保存到 /sdcard/Mihomo配置.yaml

订阅与名单

订阅地址

每行一个，必须是 Clash / Clash.Meta 格式。为空则 Mihomo 无法启动。注意: 订阅链接会明文保存在 setting.conf

排除节点

在智能选择、自动选择等组内排除，多个用 | 分隔

应用白名单

开启用白名单，关闭用黑名单(只影响 TUN 规则)

白名单模式

模式 1：仅包含名单内 App；模式 2：排除名单外的所有 App

黑名单 WIFI

每行一个 SSID，连上这些 WIFI 时自动停止服务

运行日志

点击「刷新」查看最近日志
保存后会自动重启服务，约需数秒。直通开关也可以不重启：守护循环会在 5 秒内让它生效。

工具

模块

配置备份

备份内容: setting / AdGuardHome / SmartDNS / Mihomo / 黑白名单 / hosts / 定时，保留最近 5 份。
